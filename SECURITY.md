# Security

Use GitHub's private vulnerability reporting on this repository's Security tab
when available. Otherwise contact the repository owner privately through an
existing channel; do not disclose credentials or exploitable details publicly.

Include the affected commit, impact and a minimal reproduction using test data.
Never send wallet keys, operator passwords, session keys or customer data.

Only the current `main` branch is maintained. This initial release has automated
authorization and browser tests but has not received an independent security
audit. Configure HTTPS and fresh credentials as described in the README. Keep
the merchant API key on the server; the dashboard is read-only and single-operator.
